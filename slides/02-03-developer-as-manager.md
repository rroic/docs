# Bullets

bullet-1-title: The role shifts from doing to directing
bullet-1-body: When an agent handles the execution — writing the boilerplate, wiring the service, scaffolding the tests — the developer's job moves up a level. The question changes from "how do I write this?" to "what should this do, and how do I know it's right?"

bullet-2-title: New muscles need to be developed
bullet-2-body: The flight level changes — from 100ft to 10,000ft. Less concern with the micro perspective of individual lines and implementation details, more with the macro view of architecture, intent, and correctness at scale. That's a different skill set, and it needs to be deliberately built.

bullet-3-title: Decomposition and judgement
bullet-3-body: Breaking a problem into agent-sized tasks, sequencing them correctly, knowing when to intervene — this is where developer mastery concentrates. The developers who do this well ship faster and with less rework.

bullet-4-title: Accountability stays with the developer
bullet-4-body: The agent doesn't own the outcome — the developer does. Managing an agent is still managing. The code that ships is yours, which means understanding what it does is still non-negotiable.
