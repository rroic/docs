# Bullets

bullet-1-title: Design patterns are ubiquitous
bullet-1-body: Most mainstream languages today are typed, object-oriented and C-style syntaxed. ORM is an ORM in Java, Node and C#. Singletons are singletons everywhere. Frontend state management, local storage, callbacks, services, etc. exist across all frontends.

bullet-2-title: Technology boundaries are softening
bullet-2-body: A Java developer won't remain just a Java developer. The patterns are the same; the agent handles the syntax. Backend developers will move across Java, Node, Python, C# — and the same is true on the frontend across React, Vue, Angular, and whatever comes next.

bullet-3-title: Documentation is built in
bullet-3-body: Markdown files as standards, Prompts as business logic and Agents being able to understand and explain technical architecture. System is now being documented by default

bullet-4-title: NEVERs become SOMETIMESs
bullet-4-body: A Java backend developer setting up a Node project. A frontend dev writing a database migration. Things that were off the table — not because of ability, but because of the cost of crossing the gap — will start happening. Not always. Not for everyone. But much more often than before.
