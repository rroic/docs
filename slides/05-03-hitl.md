# Content

content-heading: Human-in-the-Loop is not just an engineering checkpoint — it is a trust moment
content-body: Every HITL point is a UX design problem. The agent pauses, must surface enough context for a human decision, collect that decision, and resume. How this is designed determines whether the user will trust the agent — or not.

bullet-1-title: Minimum viable context
bullet-1-body: The user needs enough to decide — not a full trace of the agent's reasoning. A wall of logs is not transparency.

bullet-2-title: Confidence, not certainty
bullet-2-body: Agents are probabilistic. Show confidence level, not a false binary of right and wrong.

bullet-3-title: Reversibility as a design constraint
bullet-3-body: Every approval gate needs an undo path. If an action is irreversible, the UI must make that clear before the user approves — not after.

bullet-4-title: Transparency layer
bullet-4-body: Every agent needs a persistent, human-readable log of what it decided and why. Not a debug log — a user-facing artefact.
