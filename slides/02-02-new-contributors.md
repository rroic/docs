# Bullets

bullet-1-title: BA: The divide between specs and code is getting narrower
bullet-1-body: Specifications sit alongside the code they describe, in a well-architected system BA can sometimes propose code updates to match the spec.

bullet-2-title: QA: test cases that become automation
bullet-2-body: An agent creates test cases from specs inside the codebase. Those cases turn into automation scripts without the QA being an automation expert, helping generalists to become SDETs. 

bullet-3-title: UX: visual changes without a handoff queue
bullet-3-body: Minor frontend updates — a spacing fix, a colour correction, a component tweak — are within reach directly in the codebase. A developer reviews and merges.

bullet-4-title: All grounded in source code repo
bullet-4-body: The common thread: each of these contributions happens inside the code repository – which becomes the source of truth for the whole team, not just for developers.
