# Content

content-heading: Same craft, new questions — and some genuinely new territory
content-body: UX skills map directly onto agentic work. Interaction design, user research, information architecture, UX writing — all still apply. What's new is what we apply them to.

bullet-1-title: Interaction design → agentic flow design
bullet-1-body: We already think in multi-step processes, error states, edge cases. When an agent executes the steps instead of the user, the design questions are the same — but the stakes are higher.

bullet-2-title: User research → AI behaviour evaluation
bullet-2-body: Same methods, different subject. Instead of "does this button make sense", we ask "does this person trust what the agent just did?"

bullet-3-title: Information architecture → knowledge architecture
bullet-3-body: How content and data are structured determines what an agent can actually do with it. Often overlooked. Real differentiator.

bullet-4-title: What's genuinely new
bullet-4-body: Designing for uncertainty. Classic UX is deterministic — user does X, system does Y. AI introduces probabilistic behaviour. The design has to hold up when the agent does something unexpected.
