# Content

content-heading: Voice UI, Chat UI, and Agentic UI — each requires a different approach
content-body: Not everything is a chatbot. The difference between designing a scripted bot and an LLM-backed interface is like the difference between a flowchart and designing for someone who can say anything, in any order, and still expect a coherent response.  

* [Notch AX patterns]([https://upskilling.wearenotch.com/](https://ax-pattern-library.vercel.app/))

bullet-1-title: Voice UI
bullet-1-body: No screen, no click. Everything is conversation — designing for rhythm, silence, and orientation without any visual anchors.

bullet-2-title: Chat UI
bullet-2-body: Looks familiar. It isn't. The LLM can say anything in any order — the design has to hold up when it does.

bullet-3-title: Agentic UI
bullet-3-body: The agent doesn't answer questions — it takes actions. We design the transparency layer: what did it do, how do you stop it, how do you correct it.

bullet-4-title: No settled patterns yet
bullet-4-body: We are building them as we go. That's a good place for a UX team — we are experts at designing in uncertainty.
