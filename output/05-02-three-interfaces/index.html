Three interfaces we design for now

architecture

Voice UI, Chat UI, and Agentic UI — each requires a different approach

Not everything is a chatbot. The difference between designing a scripted bot and an LLM-backed interface is like the difference between a flowchart and designing for someone who can say anything, in any order, and still expect a coherent response.

Notch AX patterns)

Voice UI

No screen, no click. Everything is conversation — designing for rhythm, silence, and orientation without any visual anchors.

Chat UI

Looks familiar. It isn't. The LLM can say anything in any order — the design has to hold up when it does.

Agentic UI

The agent doesn't answer questions — it takes actions. We design the transparency layer: what did it do, how do you stop it, how do you correct it.

No settled patterns yet

We are building them as we go. That's a good place for a UX team — we are experts at designing in uncertainty.
